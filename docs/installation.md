# Installation

## Python dependencies

```bash
python -m pip install -r requirements.txt
```

## Linux system dependencies (later phases)

Install as needed on your distribution (examples):

- Debian/Ubuntu: `sudo apt install udisks2 parted util-linux wimtools`
- Fedora: `sudo dnf install udisks2 parted util-linux wimlib-utils`

The app's **Settings → Dependency check** reports what is available on the current system.
